STONEFORM CONSTRUCTION — DEMO WEBSITE

WHAT THIS IS
A mobile-first, premium-style construction company landing page concept.
It uses HTML, CSS and JavaScript and can be hosted as a static website.

FILES
- index.html: page content and sections
- styles.css: design and responsive layout
- script.js: mobile navigation, quote form demo behaviour
- README.txt: these instructions

IMPORTANT BEFORE SHOWING AS A REAL CLIENT WEBSITE
1. "Stoneform Construction" is a fictional demo brand. Replace the company name and copy.
2. Replace hello@stoneform.example with the client's real email.
3. Replace the demo location/service areas with accurate details.
4. Replace the illustrative architectural photos with the client's real project photos or properly licensed images.
5. Open script.js and set whatsappNumber to the client's WhatsApp number in international digits-only format, without + or spaces. Example format: 263771234567.
6. Test the WhatsApp button/form, phone links, spelling, images and layout on a phone.
7. Do not claim the demo photos are the client's work, and do not publish fake testimonials or credentials.

PUBLISHING
This is a static website. Upload index.html, styles.css and script.js to a GitHub repository, then import that repository into Vercel. The project root is the folder containing index.html. No build command is required for this plain static site.

IMAGE AND FONT NOTES
This demo loads remote images from Unsplash and fonts from Google Fonts, so internet access is required for those resources. Confirm the licensing and client approval for all assets before commercial use.
